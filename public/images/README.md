# PS ChemLab image assets

Public images use stable, lowercase filenames and are served directly from `/images`.

- `branding/` — logos and Open Graph artwork
- `portraits/` — people and profile portraits
- `software/<software-slug>/` — `screenshot-1.webp`, `screenshot-2.webp`, and `screenshot-3.webp`
- `courses/<course-code>/` — course thumbnail images
- `publications/<publication-id>/` — `graphical-abstract.webp` and related publication artwork

Prefer WebP for photography and screenshots, SVG for branding, and descriptive alternative text in the consuming component.
